# Transcriptional Responses of Mycobacterium  tuberculosis to Hypoxia, Rifampicin  Exposure and Iron Starvation 
Mycobacterium tuberculosis (Mtb) adapts to hostile host environments through extensive transcriptional reprogramming. Environmental stresses such as hypoxia, antibiotic exposure, and nutrient deprivation induce distinct physiological states that enable bacterial persistence and survival. Understanding these transcriptional adaptations is essential for identifying conserved stress-response mechanisms and condition-specific regulatory pathways. The objective of this study was to develop a reproducible computational pipeline for analyzing transcriptomic responses of Mtb H37RV strain across three biologically distinct stress conditions: Hypoxia, Rifampicin exposure and Iron starvation. Differential expression analysis was performed independently within each experimental study, followed by cross-condition comparison to identify shared and unique stress-responsive genes.

RNA-seq samples for each stress condition were identified from the Gene Expression Omnibus (GEO) and processed using a bash-based pipeline: raw FASTQ files were quality-checked with FastQC, MultiQC, trimmed with Trimmomatic, aligned to the M. tuberculosis H37Rv reference genome using Bowtie2, RNA strandedness was inferred using infer_experiment and quantified into gene-level count matrices using featureCounts. The resulting RNA-seq count matrices were analyzed using DESeq2. Quality assessment was performed through variance stabilizing transformation (VST) and principal component analysis (PCA). Differential expression analysis was conducted independently for each condition using shrinkage estimation of log2 fold changes with apeglm. Significant genes were identified using adjusted p-value <0.05 and |log2FC|>1. Downstream analyses included volcano plots with significant genes per condition, Venn diagrams and concordance analysis of common genes, and KEGG enrichment.

The framework provides a reproducible strategy for comparative transcriptomic analysis of Mtb H37RV strain in different functional states while avoiding incorrect statistical modeling caused by study-condition confounding.
